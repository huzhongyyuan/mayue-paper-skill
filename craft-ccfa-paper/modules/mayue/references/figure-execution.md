# 图表规划、图注和实际绘制

与 `figure-playbook.md` 配合使用。本文件处理从用户材料到交付图的执行；配色、作者原图证据、四张 SVG 的适用条件见该 playbook。

## 根据请求直接进入相应工作

- **“写图／规划图”**：给每张图写一句命题、panel 草案、所需素材、正文引用位置和图注草稿。不要把写图理解成只润色已有 caption。
- **“写图注”**：先读取真实图及对应方法／协议，完成可直接粘贴的 caption；仅存在草图时明确其内容仍是结构示意。
- **“画图／改图”**：读取方法和素材，实际生成或修改可编辑文件，再渲染检查。不能只返回绘图 prompt 或建议。
- **“按某张图的风格”**：学习分区、信息层级、语义颜色和对齐方式；使用用户的方法和新构图，避免照搬原图或替换几个标签即声称是新方法。

## 开画前的语义表

简单图可在工作中维护，不必强制用户填表。

| 对象 | 应明确的内容 |
|---|---|
| 节点 | 名称、输入／输出、张量或对象类型、来自已有模型还是本研究新增 |
| 连接 | 数据流、条件注入、特征复用、监督、梯度或时序推进；箭头起终点 |
| 状态 | 哪个训练阶段更新，推理是否存在，是否产生逐样本优化开销 |
| 面板 | 主命题、与总图的对应位置、放大解释的操作 |
| 样例 | 原始文件、样例 ID、时间点、裁剪坐标、模型配置 |
| 数值 | 日志来源、统计方式、单位、误差条含义、成本计算范围 |

不明确的连接会改变计算含义时，先查实现。若材料仍不足，画明确标注的待确认示意，并指出具体未决连接，不能自行发明模块。

## 工具选择与实际产物

**架构、模块、时间轴**优先 SVG／矢量 PDF；可用 `assets/` 的模板及 `scripts/generate_templates.py` 起稿，再按实际语义改节点、路线和分区。SVG 文件中的文本、箭头、形状保持独立对象，分组使用有意义的 ID。不要把整图变成一张不可编辑截图。

**用户指定 PPTX**时优先原生形状、连接线和可编辑文字；视频样例可以是位图。使用环境中可用的 presentations 工具或库。没有验证 SVG 转形状的兼容性时，不把“把 SVG 插进 PPT”称作完全可编辑的 PPT 图。

**数值图**从真实日志用 Matplotlib 等程序绘制，保留绘图脚本与整理后的数据；方法比较保持相同统计协议。不可生成看起来合理的曲线、误差条或优越数字。

**定性对比图**程序拼版真实样例，保持时间点、比例和裁剪可比；若某方法缺输出则保留缺项或调整比较，不能用生成图补结果。只对非证据性的概念插画使用图像生成。

没有用户方法时，本技能提供的四张图就是明确标注的原创结构模板；不能给它们附上研究效果描述。

## Caption 的四种职责

| 图类型 | 应写清什么 | 不应顺手声称什么 |
|---|---|---|
| Framework | 任务与路径、panel 对应、关键操作、线型和参数状态 | 架构示意本身证明模型有效 |
| Motivation | 改什么、固定什么、图中观察、受限解释 | 单样例证明普遍因果机制 |
| Qualitative | 输入与控制、行列／时间的读法、可见差异、必要设置 | 肉眼难判断的定量提升 |
| Quantitative / Ablation | 横纵轴／指标与方向、协议、统计单位、比较对象、误差条 | 缺重复实验时假设有统计显著性 |

顺序可采用：一句主题 → panel 读法 → 符号／协议 → 图支持的具体认识。定义和条件较少时保持短图注；复杂图无需机械限制句数。

原创框架图注骨架：

> Overview of [method] for [task]. (a) [input] is mapped to [representation]. (b) [operation] injects [signal] into [location]. Solid arrows indicate [meaning], and dashed arrows denote [meaning]. [Training-only branch] is removed during inference.

只有真实移除分支时才保留最后一句。若框架不存在两块 panel，就按实际面板重写。

原创结果图注骨架：

> Comparison under [protocol]. Rows show [methods], and columns correspond to [inputs / timesteps / conditions]. All results use [verified shared setting]. The highlighted regions illustrate [observable, bounded difference].

定量表 caption 还要解释加粗、下划线、最好／次好、数值方向与公平设置；未核实的协议在草稿中标注待补，不能默认大家同算力。

## 验证和交付

先逐箭头核对算法，再检查视觉。按最终栏宽渲染，查看标签是否可读、是否有遮挡截断、线是否穿字、颜色是否同时有文字／位置线索、图例是否完整。传给模型分析或展示过程时保留原图，另导出尽量小于 200,000 字节的清晰预览；小字问题只裁剪相关区域。

最终交付包含：可编辑源文件、论文可用的高质量导出（工具支持时）、已检查预览、可直接使用的图注。数值图附数据与脚本。说明实测过的格式和尚未确认的路径；不要声称未测试过的软件编辑兼容性。
